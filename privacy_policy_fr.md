# Politique de Confidentialité — RARI

**Dernière mise à jour :** 2026-05-02
**Date d'entrée en vigueur :** 2026-05-02

Cette Politique de Confidentialité décrit comment RARI (« nous ») collecte, utilise et partage vos informations lorsque vous utilisez notre application mobile (l'« App »). Nous nous engageons à protéger votre vie privée.

## 1. Informations que nous collectons

### 1.1 Informations que vous fournissez
- **Compte :** adresse email, mot de passe (chiffré), nom d'affichage, nom d'utilisateur
- **Profil :** image avatar, pays, ville, préférences
- **Communications :** messages envoyés via le chat, tickets de support, contestations de bannissement

### 1.2 Informations collectées automatiquement
- **Données de jeu :** parties jouées, scores, historique victoires/défaites, replays, succès
- **Progression :** XP, niveau, prestige, niveau de supporter, items débloqués
- **Données de l'appareil :** type d'appareil, version OS, langue, identifiant pour notifications push
- **Utilisation :** interactions, rapports de crash, métriques de performance

### 1.3 Informations de tiers
- **OAuth :** si vous vous connectez avec Google ou Apple, nous recevons votre email et profil basique
- **Achats :** RevenueCat nous communique le statut de votre achat (nous ne recevons PAS vos données de carte — elles restent chez Apple ou Google)

## 2. Comment nous utilisons vos informations

- Fournir et maintenir le jeu
- Authentifier votre compte et prévenir la fraude
- Vous mettre en relation avec d'autres joueurs en ligne
- Suivre votre progression, succès et achats
- Envoyer des notifications push (invitations, défi quotidien, tournois)
- Personnaliser votre expérience (traductions, recommandations)
- Afficher des publicités (si vous n'êtes pas supporter payant)
- Détecter et prévenir les activités frauduleuses
- Respecter nos obligations légales

## 3. Services tiers

| Service | Rôle | Données partagées |
|---------|------|-------------------|
| **Supabase** | Hébergement backend | Toutes les données de compte et de jeu |
| **Firebase** (Google) | Crashlytics, notifications push, OAuth | Rapports de crash, tokens, profil OAuth |
| **RevenueCat** | Gestion des achats in-app | ID utilisateur, historique d'achats |
| **Google AdMob** | Publicité | Identifiant anonyme, données d'interaction |
| **Apple / Google** | Distribution et OAuth | Données de connexion, paiement (nous ne voyons pas la carte) |

Chaque service a sa propre politique. Nous vous recommandons de les consulter.

## 4. Partage et divulgation

Nous **ne vendons pas** vos données personnelles. Nous partageons les données uniquement :
- Avec les tiers ci-dessus (pour fournir le service)
- Si requis par la loi (ordonnances judiciaires)
- Pour protéger les droits, biens ou sécurité de RARI ou des utilisateurs
- En cas de transfert d'entreprise (fusion, acquisition) — vous serez notifié

## 5. Vos droits

Selon votre localisation, vous avez les droits suivants :
- **Accès :** demander une copie de vos données
- **Correction :** demander la correction de données inexactes
- **Suppression :** supprimer votre compte via Paramètres → Supprimer le compte
- **Portabilité :** recevoir vos données dans un format portable
- **Opposition :** vous opposer à certains traitements (ex. publicité)
- **Retrait :** retirer votre consentement

Pour exercer ces droits, contactez **rari.app.haiti@gmail.com**.

## 6. Confidentialité des enfants

RARI est destiné aux utilisateurs de **13 ans et plus**. Nous ne collectons pas sciemment de données d'enfants de moins de 13 ans. Si vous pensez que nous avons collecté des données d'un enfant de moins de 13 ans, contactez-nous immédiatement.

Pour les utilisateurs de l'Union Européenne, l'âge minimum est **16 ans** (RGPD).

## 7. Conservation des données

Nous conservons vos données tant que votre compte est actif. Si vous supprimez votre compte :
- Les données personnelles sont supprimées dans les **30 jours**
- Les données agrégées et anonymisées peuvent être conservées pour analytics
- Certaines données peuvent être conservées plus longtemps si requis par la loi

## 8. Sécurité

Nous utilisons des mesures de sécurité standard de l'industrie :
- Transmission chiffrée (HTTPS/TLS)
- Mots de passe chiffrés (bcrypt via Supabase)
- Sécurité au niveau des lignes de base de données
- Audits réguliers

Aucune méthode de transmission n'est 100% sécurisée.

## 9. Transferts internationaux

Vos données peuvent être traitées dans d'autres pays (serveurs Supabase, Firebase). Nous nous assurons que des garanties appropriées sont en place.

## 10. Cookies et tracking

Notre App n'utilise pas de cookies traditionnels, mais :
- Google AdMob peut utiliser des identifiants pour personnaliser les pubs
- Vous pouvez désactiver la personnalisation dans les paramètres de votre appareil

## 11. Modifications

Nous pouvons mettre à jour cette politique. Les changements importants seront communiqués via :
- Notification in-app
- Email (à l'adresse de votre compte)
